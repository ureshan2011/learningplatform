Consequently:

- **Brand mark** — typographic only. Use the `Wordmark` component (`components/core/Wordmark.jsx`), which renders `ictcampus.` in Manrope 800 with an orange period. When real files arrive, drop `assets/logo.svg` in here and change only that component.
- **Icons** — Lucide via CDN (`https://unpkg.com/lucide@0.454.0/dist/umd/lucide.js`). Substitution flagged in `readme.md` § ICONOGRAPHY.
- **Photography / illustration** — none on hand. UI kits use flat orange/white tiles with single-colour line icons where a course thumbnail or hero photo would sit, and label them as placeholders.
