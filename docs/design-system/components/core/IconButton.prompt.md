Circular icon-only button — arrow badges on cards, close buttons, toolbar actions.

```jsx
<IconButton variant="brand" label="Open project"><Arrow/></IconButton>
<IconButton variant="onDark" size={36} label="Next"><Arrow/></IconButton>
```

Variants: `soft` (orange on cream tint), `brand`, `dark`, `onDark` (for near-black panels), `outline`.
