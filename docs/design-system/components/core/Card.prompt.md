Container surface. Pick the variant by world: cream marketing vs dark product.

```jsx
<Card>White card, soft shadow, 20px radius</Card>
<Card variant="dark">App panel: hairline border, no shadow</Card>
<Card variant="framed" padding={12}>Portfolio card with near-black frame</Card>
<Card variant="feature" padding={32}>The one cocoa hero banner per screen</Card>
```

Dark cards never get drop shadows — they use a 1px inset white highlight instead.
